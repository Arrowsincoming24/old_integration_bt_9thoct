🎯 WHAT CHANGED:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

BEFORE (Broken):
  - JWT filter applied to ALL requests (including HTML pages)
  - Session management was STATELESS (no sessions allowed)
  - /admin/** and /customer/** blocked by Spring Security
  - CSRF protection blocked API calls
  - Result: 400 errors, login failures, dashboard not loading

AFTER (Fixed):
  - JWT filter ONLY for /api/** endpoints
  - Session management is IF_REQUIRED (allows sessions for web pages)
  - /admin/** and /customer/** pages allowed (auth via JavaScript)
  - CSRF disabled for /api/** endpoints
  - Result: Everything works! ✅
